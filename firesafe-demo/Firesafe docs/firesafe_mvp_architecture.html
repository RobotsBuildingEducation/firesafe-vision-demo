FireSafe Vision MVP feature set and technical architecture overview

In scope — MVP
in

Photo upload + zone selector

Homeowner uploads a property photo and selects which zone they want assessed (Zone 0, 1, or 2). Mobile-first, works on field visits.

in

Property condition intake

Short form: topography type, current vegetation, fence material, existing hardscaping. Feeds the prompt context for generation.

in

AI vision analysis

Claude or GPT-4 Vision reads the uploaded photo and surfaces hazards automatically — e.g. combustible fence in Zone 0, dense vegetation.

in

Before / after image generation

Stable Diffusion img2img conditioned on a fire-resilient design prompt. Generates a transformed version of the same property photo.

in

Recommendations output

Zone-specific action list with materials (gravel, fiber cement, metal fencing), native plant species for SoCal, and spacing guidance from the USGBC-CA curriculum.

in

Shareable PDF report

One-page output: before/after image, hazard flags, recommended actions, plant list. Designed to hand to a contractor or bring to a city permitting office.

Out of scope — v1
out

Contractor matching

Directory integration deferred. v1 links to USGBC-CA professionals directory.

out

Permit filing

Regulatory complexity varies by jurisdiction. Out of scope for prototype.

out

3D site modeling

LiDAR / parcel data integration is a v2 consideration tied to SGVCOG data access.

Future additions
later

Neighborhood view

Aggregate risk score for a block — useful for FireSafe Council and COG outreach.

later

Multilingual

Spanish first — critical for Altadena/Pasadena affected populations.

later

Incentive finder

Auto-surface rebates and grants relevant to recommended upgrades.

Frontend
frontend

Next.js + React

Mobile-first PWA. Works offline for intake form — uploads queue when connection returns. Deployed on Vercel or Netlify.

frontend

UI components

Tailwind CSS. Photo upload with preview, zone selector map overlay, step-by-step intake form, before/after image slider, PDF export via react-pdf.

Backend
backend

Next.js API routes

Serverless functions handle: image upload to storage, vision analysis call, generation call, recommendation assembly, PDF generation. No separate server needed for MVP.

backend

Supabase

Postgres for session/report storage. Storage bucket for uploaded and generated images. Row-level security so homeowner data stays private. Free tier covers MVP scale.

AI layer
AI

Vision analysis

Claude API (claude-sonnet-4-6). Reads photo + intake form, outputs structured hazard JSON: zone, risk factors, recommended changes.

AI

Image generation

Stable Diffusion via Replicate API (img2img). Conditioned on property photo + fire-resilient design prompt built from hazard JSON.

AI

Knowledge base (RAG)

USGBC-CA course content + CAL FIRE defensible space rules chunked and embedded. Retrieved context shapes the recommendation output. Pinecone or pgvector.

Infrastructure
infra

Open source repo

MIT license on GitHub. Documented for fork — other COGs, nonprofits, and community groups can deploy their own instance with their own API keys.

infra

Cost model

API costs: ~$0.10–0.25 per report (vision analysis + image generation). PDF generation free. Supabase free tier. Grant-funded API budget for nonprofit deployment.

Build roadmap
Weeks 1–2

Foundation

Repo setup, Next.js scaffold, Supabase config, API key wiring, photo upload + storage working end-to-end.

Weeks 3–4

Vision + intake

Claude vision call returning structured hazard JSON from photo. Intake form UI. Prompt engineering for SoCal fire context.

Weeks 5–6

Generation

Stable Diffusion img2img integration via Replicate. Before/after UI with image comparison slider. Prompt tuning for native plant rendering.

Weeks 7–8

Output + RAG

Recommendation engine with RAG against USGBC-CA content. PDF report generation. End-to-end flow tested with real property photos.

Week 9

Launch

Docs, open source release, pilot with one community partner (SGVCOG or CA FireSafe Council).

Developer profile needed

Core skills

React / Next.js, REST API integration, basic prompt engineering. One full-stack developer can carry this for MVP — estimated 200–250 hours total.

Nice to have

Experience with image generation APIs (Replicate / Stability AI), vector databases (pgvector or Pinecone), and PDF generation in React.

Key risks and mitigations

Image generation fidelity

SD img2img may produce generic or implausible outputs that don't match the actual property.

Mitigation: use ControlNet for structure preservation; build a human review step before PDF is finalized in v1.

Homeowner trust

AI-generated recommendations touching someone's home post-trauma requires careful framing.

Mitigation: frame as "inspiration, not instruction" — always point to a licensed professional for execution. Trauma-informed UX copy.

API cost at scale

$0.15–0.25 per report is manageable at pilot scale but needs a grant budget for broader deployment.

Mitigation: batch generation, cache common prompts, apply for Anthropic nonprofit credits and Replicate open source tier.

Regulatory accuracy

Zone rules vary by jurisdiction — Altadena, Pasadena, Arcadia all differ slightly.

Mitigation: RAG knowledge base is jurisdiction-tagged. v1 scopes to LA County unincorporated + Altadena only, clearly disclosed.
